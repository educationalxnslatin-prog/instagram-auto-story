# Instagram Auto Story

Простой Python-скрипт для ежедневной автоматической публикации **Instagram Story** с **Link-стикером**. Берёт фото из локальной папки `media/`, подгоняет под формат stories (1080x1920), публикует и переносит файл в `posted/`.

> ⚠️ **Внимание:** скрипт работает через неофициальную библиотеку [`instagrapi`](https://github.com/subzeroid/instagrapi), которая использует приватный мобильный API Instagram. Это **нарушает Terms of Service Instagram** — есть риск временной блокировки или бана аккаунта (особенно у новых аккаунтов и при ежедневной автоматизации с одного IP). Используйте только на тестовых аккаунтах.

---

## Возможности

- Логин по логину/паролю + сохранение сессии (повторный логин не нужен)
- Поддержка 2FA через TOTP-секрет
- Поддержка прокси
- Случайный или алфавитный выбор фото из `media/`
- Автоматическая подгонка под 9:16 (с чёрными полями, если нужно)
- **Link-стикер** (кликабельная ссылка в story)
- Перенос опубликованных фото в `posted/` (чтобы не повторялись)
- Подробный лог в `logs/post_story.log`
- Режим `--dry-run` (всё, кроме реальной публикации)

## Установка

### Требования
- Python 3.10+
- pip

### Шаги

```bash
# 1. Клонировать репозиторий
git clone <repo_url>
cd instagram-auto-story

# 2. (Опционально) создать виртуальное окружение
python -m venv .venv
source .venv/bin/activate   # Linux / macOS
# .venv\Scripts\activate    # Windows

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Создать .env из примера
cp .env.example .env
# Откройте .env и заполните IG_USERNAME / IG_PASSWORD

# 5. Положить фотографии в media/
cp ~/Pictures/my_story.jpg media/
```

## Конфигурация

### `.env`
Учётные данные и приватные настройки (НЕ коммитить!):
```ini
IG_USERNAME=your_login
IG_PASSWORD=your_password
IG_TOTP_SEED=         # опционально, для 2FA
IG_PROXY=             # опционально, например http://user:pass@host:port
```

### `config.json`
Публичная конфигурация. Основные поля:

| Поле | Описание | Значение по умолчанию |
|---|---|---|
| `media_dir` | Откуда брать фото | `media` |
| `posted_dir` | Куда переносить после публикации | `posted` |
| `session_file` | Где хранить сессию Instagram | `sessions/session.json` |
| `selection` | `random` или `alphabetical` | `random` |
| `move_after_post` | Переносить ли фото в `posted/` после публикации | `true` |
| `link_sticker.enabled` | Включить ли Link-стикер | `true` |
| `link_sticker.url` | URL ссылки | `https://example.com` |
| `link_sticker.sticker_text` | Текст на стикере (если поддерживается) | `""` |
| `caption` | Текст поверх story (обычно не виден в stories, но instagrapi его принимает) | `""` |
| `image.auto_resize` | Подгонять под 1080x1920 | `true` |

## Запуск

### Разово (в консоли)
```bash
python post_story.py
```

### Без реальной публикации (dry-run)
Проверяет логин, выбор и подготовку фото — но НЕ публикует:
```bash
python post_story.py --dry-run
```

### Конкретное фото
```bash
python post_story.py --image media/special.jpg
```

## Ежедневный запуск

Есть **три варианта**, выбирайте удобный.

### Вариант 1: cron (Linux / macOS) — рекомендуется

Открыть редактор crontab:
```bash
crontab -e
```

Добавить строку (запуск каждый день в 10:00):
```cron
0 10 * * * cd /полный/путь/до/instagram-auto-story && /полный/путь/до/.venv/bin/python post_story.py >> logs/cron.log 2>&1
```

Проверить, что запись добавилась:
```bash
crontab -l
```

### Вариант 2: Планировщик заданий (Windows)

1. Открыть **Планировщик заданий** (Task Scheduler)
2. Создать задачу → триггер «Ежедневно» → время
3. Действие: «Запустить программу»
   - Программа: `C:\path\to\python.exe`
   - Аргументы: `post_story.py`
   - Рабочая папка: `C:\path\to\instagram-auto-story`

### Вариант 3: Встроенный демон (Python-процесс)

Если cron / Task Scheduler недоступны, можно запустить долгоживущий процесс:

```bash
# В .env добавить:
# POST_HOUR=10
# POST_MINUTE=0
# TIMEZONE=Europe/Moscow

python run_daemon.py
```

Чтобы он работал в фоне:
```bash
nohup python run_daemon.py > logs/daemon.log 2>&1 &
```

> ⚠️ При этом ваш компьютер должен быть включён в нужное время.

## Возможные проблемы

### `ChallengeRequired`
Instagram заметил «подозрительный» вход и просит подтвердить через email/SMS.

**Решение:** залогиньтесь вручную в браузере / приложении с того же IP, пройдите challenge и попробуйте снова. Желательно использовать стабильный IP (домашний или VPS, **не публичные прокси**).

### `TwoFactorRequired`
На аккаунте включена двухфакторная аутентификация, но `IG_TOTP_SEED` не задан.

**Решение:** в настройках Instagram → Безопасность → Двухфакторная аутентификация → выберите «Приложение для аутентификации». При генерации QR-кода скопируйте **секретный ключ** (base32-строка без пробелов) и положите его в `.env` как `IG_TOTP_SEED`.

### Link-стикер не появляется в story
Раньше Link-стикер был доступен только аккаунтам с 10k+ подписчиков. Сейчас Meta открыла его всем, но иногда на новых/малоактивных аккаунтах он может быть недоступен — это решает Instagram.

**Проверка:** попробуйте добавить ссылку вручную через приложение Instagram. Если там не работает — через скрипт тоже не получится.

### Аккаунт заблокирован
Instagram активно борется с автоматизацией. Чтобы снизить риск:
- Не используйте дешёвые публичные прокси
- Не публикуйте больше 1-2 stories в день
- Иногда заходите в аккаунт вручную с того же IP
- Используйте только тестовые аккаунты

## Структура проекта

```

├── post_story.py         # Основной скрипт
├── run_daemon.py         # Опциональный демон-планировщик

```
